AstrBot 桌面版 · 安装前说明

这个安装程序装的是 AstrBot（开源多平台 LLM 机器人框架）的 Windows 桌面版构建产物：
原生启动器 + 无控制台窗口核心 + 内嵌管理面板 + QQ 接入表单 + 扫码登录。

上游项目：https://github.com/AstrBotDevs/AstrBot   官网：https://astrbot.app
本包内 AstrBot 代码遵循其原许可证 AGPL-3.0，许可证原文见安装后的 LICENSE-AstrBot.txt。

安装会做什么
  · 默认只装给当前用户（目录是 %LOCALAPPDATA%\Programs\AstrBot），不需要管理员权限；
    想装成「所有用户可用」，在下一步的对话框里改选即可（那时会要一次管理员授权）。
  · 不会动已有的 data\ 目录：机器人配置、插件、聊天记录数据库都在里面。
    覆盖安装 = 只换程序文件，配置原样保留。
  · 会创建开始菜单项和（可选）桌面快捷方式，并在「应用和功能」里登记卸载入口。

第一次启动后要做的事
  1. 窗口里会显示面板的初始密码（用户名 astrbot），登录后请先改掉；
  2. 接 QQ 官方机器人就直接点「扫码登录」，用手机 QQ 扫一下，不用手抄 AppID/密钥；
  3. 详细用法、故障自查、导出诊断包都在同目录 README.txt 里。

关于 Windows 的「未知发布者」提示
  这两个 exe 与安装包都带了本次构建的自签代码签名（可用包内 astrbot-signing.cer 核对
  文件有没有被改过），但自签证书没有权威机构背书，所以 SmartScreen 仍可能弹一次提示。
  这不是文件被篡改的信号；要彻底不弹，需要购买正式的代码签名证书。
