AstrBot 桌面版 · 安裝前說明

這個安裝程式內容為 AstrBot（開放原始碼多平台 LLM 機器人框架）的 Windows 桌面版建置成果：
原生啟動器 + 無主控台視窗核心 + 內嵌管理面板 + QQ 接入表單 + 掃描登入。

上游專案：https://github.com/AstrBotDevs/AstrBot   官網：https://astrbot.app
本包內的 AstrBot 程式碼沿用其原授權 AGPL-3.0，授權全文見安裝後的 LICENSE-AstrBot.txt。

安裝會做什麼
  · 預設只安裝給目前的使用者（目錄為 %LOCALAPPDATA%\Programs\AstrBot），不需要管理者權限；
    若要改為「所有使用者可用」，在下一步的對話框改選即可（那時會要求一次管理者授權）。
  · 不會動到已有的 data\ 目錄：機器人設定、外掛、聊天紀錄資料庫都在裡面。
    覆蓋安裝＝只更換程式檔，設定完整保留。
  · 會建立開始功能表項目與（可選）桌面捷徑，並在「應用程式與功能」中登錄移除入口。

第一次啟動後要做的事
  1. 視窗中會顯示面板的初始密碼（使用者名稱 astrbot），登入後請先更換；
  2. 要接 QQ 官方機器人就直接按「掃描登入」，用手機 QQ 掃一下，不必手抄 AppID／金鑰；
  3. 詳細用法、故障自查、匯出診斷檔都在同目錄 README.txt。

關於 Windows 的「未知發行者」提示
  這兩個 exe 與安裝檔都帶了本次建置的自簽程式碼簽章（可用包內 astrbot-signing.cer 核對
  檔案是否被竄改），但自簽憑證沒有權威機構背書，因此 SmartScreen 仍可能提示一次。
  這不是檔案被竄改的訊號；要完全不再提示，需要購買正式的程式碼簽章憑證。
